# @openlinkos/origin-core

Part of [Origin](https://origin.openlinkos.com), a local-first, cross-agent personal memory for AI coding agents. This package is the store: append-only raw mirrors, events, entries, forgetting, search, and replication.

Install the `origin` command instead: `npm install -g @openlinkos/origin`. This package is published for it and follows its version; its API is not yet stable and may change in any release before 1.0. Design and source: [github.com/openlinkos/origin](https://github.com/openlinkos/origin) ([architecture](https://origin.openlinkos.com/architecture)).
